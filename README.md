# 周囲と比べて地盤が低い土地ビューワー

国土地理院の標準地図と標高タイルをブラウザで直接読み込む、独立実装の比較試作です。元の terrain-depression-checker のコード・集計データ・画像は含みません。

WindowsではZIPを展開後，`Windowsで起動.bat` をダブルクリックしてください。Pythonでローカルサーバーを起動し，http://localhost:8765/ を開きます。手動なら `py -m http.server 8765` をこのフォルダで実行してください。地図を移動・拡大するか、上部のドロップダウンから47都道府県の県庁所在地の主要駅付近へ移動し、「周囲平均との差を計算」を押すと標高データを読み込み、地図全体の平地内平均との差が0.5 m以上の場所を水色から紫までの5段階で着色します。山地判定が可能な画素は薄いグレーで示します。移動中は標高データの読み込みと解析を中断し、再開にはボタンを押します。データ読み込み・山地分類・地点ごとの標高差計算を進捗バーに表示し、完了時には着色・山地・平地の画素数と経過秒数を表示します。地図をクリックして地点を選び「周囲平均との差を計算」を押すと、その地点の半径内の全陸地平均と暫定的な平地平均を比較します。通信できない場合は計算できません。

この版では、上部の検索欄に住所・地名を入力して「住所検索」を押すと、国土地理院の地名検索機能から最大8件の候補を取得します。候補をクリックすると地図が移動し、検索位置に印を付けます。検索語は検索ボタンを押したときに同サービスへ送信されます。住所の座標は街区・町丁目等の代表地点の場合があり、正確な敷地の位置とは限りません。検索機能は外部サービスの提供状況や仕様変更の影響を受けます。

「現在地へ」を押すとブラウザが位置情報の許可を求め、取得できた位置に移動して印と推定精度の円を表示します。GPSのない端末ではWi-Fi等から推定されるため、表示位置には誤差があります。位置取得はボタンを押したときの1回だけで、位置の追跡は行いません。ブラウザで利用する場合は HTTPS または `http://localhost` でページを開いてください。いずれの移動後も解析は自動実行せず、従来どおり「周囲平均との差を計算」を押します。

地図表示のズームは12～16、計算に使う標高タイルは DEM z12・z13・z14 から選択し、z13 を初期値とします。画面内の平地と判定された標高タイル（選択したズーム）の全画素について円内平均と差を計算します。平地が円内の有効な陸地面積の10%未満の場合は計算しません。広域表示では処理量の上限により解析を保留します。広域の事前集計、測地学的な厳密面積、データが欠けた領域の品質判定には未対応です。地理的な画素面積は cos(緯度) で近似しています。

暫定分類は、約100 m幅で評価した勾配が指定値以下で、約150 m先の16方向の標高と中心との差（最大－最小）が指定値以下の画素です。分類対象の円内陸地面積が10%未満なら判定不能とします。傾斜上限8°、周囲150 mの起伏上限50 mを初期設定とし、画面から変更できます。約50 m・150 mのサンプリング幅と角度・起伏の閾値は地形に照らして検証する必要があります。水理的な閉塞性、地表の流下経路、浸水深は評価していません。

地理院タイルを加工して作成。出典：https://maps.gsi.go.jp/development/ichiran.html

ズーム13はズーム14の約4倍の面積を1画素で表します。円内の計算対象画素数と半径の画素数が減るため高速になります。ズーム12はさらに粗く、半径250 mでは不適切な場合に拡大案内が出ます。粗いDEMでは狭い凹地・細い堤防などが見えなくなり、平地分類も変化します。

背景地図の初期設定は「自動」です。場所を探す間は標準地図を表示し、計算結果または地形表示の描画後には淡色地図を白黒にして表示します。移動などで結果を消すと標準地図に戻ります。手動で淡色地図（白黒）・淡色地図（元の配色）・標準地図にも切り替えられます。白黒の処理は背景地図だけに適用し、標高や低地の解析値・着色は変更しません。

「地形表示」は独立した診断機能です。現在の画面範囲に対応する選択中のDEMズームでDEM1A→DEM5A→DEM5B→DEM5C→DEM10Bの順にタイルを読み込み、有効な画素から順に合成し、有効画素数と最小・最大標高、表示画素に使われた標高モデル別の画素数を表示します。色は画面内の最小から最大までを連続的に割り当てます。初期状態では標高50m以下にカラーテーブルの70%を配分して平野を見やすくし、線形表示も選択できます。欠測は透明にします。地形表示後に地図をクリックすると、その地点のDEM標高を確認できます。地図を動かした後は「地形表示」を押し直してください。「周囲平均との差を計算」を押すと平地・山地・低地の分類表示に戻ります。

旧版はDEM10Bだけを使用していました。DEM10Bは等高線由来であり、平野の微地形を0.5m単位で見る用途には不向きです。新しい版は利用可能な高精度モデルを画素ごとに優先し、欠測箇所を次のモデルで補います。

県庁所在地の駅付近への移動先は駅データ.jp（2019年公開データ）の駅座標を参考にしています。神戸は三ノ宮駅、福岡は博多駅、那覇は県庁前駅を採用しています。駅の座標は概略の移動先であり、行政庁舎の位置ではありません。出典：https://ekidata.jp/

リンクの共有時には、公開サイトの `social-preview-title.jpg` をOGP画像として表示するためのメタデータを設定しています。

## Priority-Floodを用いた凹地計算（今回の試作）

「凹地の深さを計算」を押すと，画面範囲とその外側のDEMを取得して，解析領域の端およびDEM欠測を出口としてPriority-Floodで仮想的に凹地を埋めます。元の標高との差が0.5 m以上の平地を着色し，山地は薄いグレーで表示します。色の5段階は旧方式と同じですが，意味する数値は「出口までの地形上の高さ」です。地図上の地点をクリックすると，その地点の計算値が右欄に表示されます。

「周囲平均との差を計算」は従来どおり半径250 m／500 m／1 km内の平地平均との比較で，「比較半径」および平地10%の条件はこの方式のみに適用します。両計算の傾斜上限と150 m起伏上限は共通です。山の画素は凹地計算で着色しませんが，出口を探索する際には山の標高も利用します。

「凹地計算の画面外余裕幅」は500 m／1 km／2 kmから選択できます（初期値1 km）。余裕幅の先に出口がある場合は計算結果が変わります。解析領域端は自由流出の出口と仮定し，欠測画素に隣接する画素も出口として扱うため，深さが過小になることがあります。端まで続く凹地，狭い堤防や排水路，暗渠，ポンプ，河川水位などは十分に表現できません。この値は実際の貯留量や予測浸水深ではありません。広い範囲・細かいDEMの組み合わせは画素数とタイル数の上限で計算を保留します。

計算部分は別スレッドのWeb Workerで動作します。地図を動かすと取得と計算を中断します。ローカルでもWorkerを読み込むため，`index.html` をダブルクリックして直接開かず，Windowsでは `Windowsで起動.bat` を使うか，このフォルダで `py -m http.server 8765` を実行し，`http://localhost:8765/` を開いてください。アドレスバーが `file:///` から始まる場合，Workerはブラウザーに遮断されます。GitHub Pagesの公開サイトではHTTPS上で利用できます。
